- Variáveis

- Armazenar nome
- Armazenar XP

&nbsp;&nbsp;&nbsp;&nbsp;- Se XP for entre 7.001 e 8.000 = Platina Diamante

&nbsp;&nbsp;&nbsp;&nbsp;- Se XP for entre 9.001 e 10.000 = Imortal
&nbsp;&nbsp;&nbsp;&nbsp;- Se XP for maior ou igual a 10.001 = Radiante
